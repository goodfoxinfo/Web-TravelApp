# TravelApp Emulation

Эмуляция туристического AI-сервиса. Цель — отработать архитектуру агентной системы перед написанием production-кода.

## Что нового (май 2026)

### Веб-прототип интерфейса (`web/TravelApp Web.html`)

Полностью статичный HTML-прототип десктопного приложения, повторяющий дизайн из Figma:

- **4-колоночный layout**: боковое меню → список → основной контент → детали
- **Сворачиваемое меню** — клик на `≡` скрывает названия, остаются иконки
- **Чат с агентом** — список агентов, живой чат с наводящими вопросами, история диалога
- **Контакты** — профили участников группы с тегами интересов
- **Агенты** — Аватар, Гид, Психолог, Исследователь, Официант

Открыть прототип: скачать `web/TravelApp Web.html` и открыть в браузере (офлайн, без сервера).

## Что реализовано

### Агентная система (6 агентов)

| Агент | Класс | Роль |
|---|---|---|
| Аватар | А | Сбор профиля клиента через диалог |
| Администратор | А | Оркестрация pipeline |
| Поисковик | А | Поиск мест через Google Maps, кеширование |
| Гид | Б | Построение маршрутов |
| Психолог | Б | Анализ совместимости группы |

Каждый агент = пара файлов: `agents/configs/{agent}.agent.yaml` + `agents/prompts/{agent}.prompt.md`

### Scoring система

- **Индивидуальный**: `Score = Σ(param_места × вес_поколения) / Σ весов + корректировки`
- **Групповой**: `Final = group_score × compatibility_factor`
- Веса по поколениям: `scoring/weights/generations.yaml`
- Нулевые фильтры: коляска, дети, сердечники — обнуляют оценку

### База знаний

SQLite (`knowledge/places.db`) — 144+ мест:
- Москва: 67 мест
- Санкт-Петербург: 56 мест
- Самара: 20+ мест (Google Maps fallback)

При поиске нового города/места — автоматический запрос в Google Places API с кешированием.

### Веб-интерфейс (бэкенд)

```bash
python web/api/server_group.py
# → http://localhost:5000
```

**Возможности:**
- Карта с цветными точками по категориям (музеи, парки, рестораны…)
- Поиск города или места — топ-10 + «Показать ещё»
- Если нет в базе → запрос Google Maps → кеш
- Групповой scoring с анализом психолога
- Русские названия мест (`name_local`)

## Быстрый старт

```bash
# Зависимости
pip install -r web/requirements.txt
pip install anthropic  # опционально, для реального Психолога

# Первичное заполнение базы (Москва + СПб, 120 мест)
python mcp-servers/searcher/handlers/init_places_db.py
python mcp-servers/searcher/handlers/update_name_local.py

# Веб-интерфейс
python web/api/server_group.py
```

## Pipeline (Администратор)

```bash
python mcp-servers/administrator/handlers/run_workflow.py --profile profiles/clients/client_002_couple.json
```

Шаги: валидация профиля → Психолог (если группа) → поиск мест → scoring → Markdown-маршрут в `trips/active/`

## Структура

```
agents/          — промпты и конфиги агентов
knowledge/       — places.db + JSON справочники
mcp-servers/     — Python-скрипты (эмуляция MCP-серверов)
  administrator/ — оркестрация
  psychologist/  — анализ совместимости
  searcher/      — Google Maps + DB
profiles/        — профили клиентов (JSON)
scoring/         — калькуляторы оценок
web/             — Flask + Leaflet карта + HTML-прототип UI
  api/server_group.py      — REST API
  templates/simple_map.html — основной интерфейс (карта)
  TravelApp Web.html        — статичный UI-прототип (Figma → HTML)
```

## API эндпоинты

| Метод | URL | Описание |
|---|---|---|
| GET | `/api/search?q=Самара&offset=0` | Поиск города/места, пагинация |
| GET | `/api/all-places` | Все места для карты |
| GET | `/api/places-db?city=Москва` | Места города |
| GET | `/api/db-stats` | Статистика базы |
| POST | `/api/analyze-group` | Анализ Психолога |
| POST | `/api/group-batch-score` | Групповой scoring |
