# Web TravelApp

Десктопный веб-прототип интерфейса TravelApp — HTML-реализация дизайна из Figma.

## Открыть онлайн

**[goodfoxinfo.github.io/Web-TravelApp/TravelApp%20Web.html](https://goodfoxinfo.github.io/Web-TravelApp/TravelApp%20Web.html)**

## Что это

Полностью статичный HTML-прототип десктопного приложения для планирования путешествий с AI-агентами. Не требует сервера — работает офлайн в любом браузере.

## Интерфейс

4-колоночный layout, повторяющий дизайн Figma:

| Колонка | Содержимое |
|---|---|
| 1 | Боковое меню (сворачивается) |
| 2 | Список (агенты / контакты / чат) |
| 3 | Основной контент (чат / профиль) |
| 4 | Детали (история диалога / изменения) |

## Разделы

- **Чат с Агентом** — список AI-агентов, живой чат с наводящими вопросами и историей диалога
- **Контакты** — профили участников группы с тегами интересов и редактированием предпочтений
- **Агенты** — Аватар, Гид, Психолог, Исследователь, Официант с описаниями
- **Места, Туры, Бронирования, Соответствия, Медиа** — структура разделов

## Особенности

- Сворачиваемое боковое меню (клик на `≡`)
- Живой AI-чат с анимацией печатания
- Наводящие вопросы встроены в поток чата
- Теги интересов с удалением
- Иконки агентов и контактов с цветовым кодированием (`#6155F5` / `#34C759`)
